# Förderplan-Assistent GE (Online-Fassung)

Diese Seite liefert nur die fertige App-Datei für den Praxistest.
Der Förderplan-Assistent GE hilft Lehrkräften an Förderschulen mit dem Förderschwerpunkt Geistige Entwicklung (NRW) beim Schreiben von Förderplänen.

Die App läuft vollständig im Browser. Sie speichert nichts auf einem Server und schickt keine Daten an einen Server. Entwürfe bleiben nur auf dem jeweiligen Gerät.

Der Quellcode liegt in einem privaten Haupt-Repository. Hier liegt ausschließlich die gebaute Einzeldatei für GitHub Pages.
